## 一、定位

**一句话**：打开就能跑的霓虹天际线跑酷——零依赖、纯 Canvas 2D、每局按种子生成，60 fps 手感，中英双语，弱网、触屏与减少动效下都能正常玩。

**面向谁**

- 想在 30 秒内进入状态的休闲玩家：无需安装、无需登录、无广告、无内购。
- 喜欢“再来一次”的挑战玩家：三档难度、按难度分离的最高分、可用 `?seed=` 分享同一张地图。
- 把“零依赖 + 可验证”当作品质的开发者：源码、测试、代码审查与验证记录全部公开，`npm test` 即可复跑。

**不做**：不做联网对战，不做内购，不采集任何数据（无第三方脚本、无埋点、无 cookie）。

**三条差异化**

1. **程序化但可跳达**：不是随机堆料——阳台、峡谷、踏脚石由生成器保证可达，825/825 栋高楼逐栋校验，起跳点前永远留有空街。
2. **手感优先**：120 Hz 定步长，郊狼时间 100 ms，跳跃缓冲 120 ms，松键 2.2× 重力截断；先把手感调对，再谈内容。
3. **可验证**：51 条单测 + 72 条真实浏览器端到端 + 5 分钟内存长跑，零依赖、本机可复跑，失败会打印实测值。

## 三、审查记录

完整记录：[`docs/CODE-REVIEW-v2.0.md`](CODE-REVIEW-v2.0.md)

- 40 条确认为真的问题：6 条 P1、14 条 P2、20 条 P3，全部修复；另有 5 条复核后判定可接受、3 条未能确认，均写明理由。
- 最严重的一类不是玩法 bug，而是**测试无法失败**：3 个验收标准的断言写成恒真式，删掉被测代码仍然通过；已改为可证伪，并做了变异验证（把 bug 放回去，确认新断言失败）。
- 第二类是 **Enter 双重动作**：焦点在按钮上按 Enter 会同时触发全局动作与按钮 click，导致“只有 HUD 的冻结画面”；已加焦点守卫并补了回归用例。
- 其余集中在测量失真（暂停页也能报 60 fps）、交互与可访问性（种子不可聚焦、空格无法激活按钮、toast 无播报、EN 按钮差 2 px）、以及测试脚手架（`waitFor` 吞异常、端口失败泄漏进程、单采样必然零增长）。

## 五、已知缺口

1. **只在 Chromium 内核（Edge）验证**：Firefox 与 iOS Safari 未覆盖，`backdrop-filter`、`env(safe-area-inset-*)`、WebAudio 自动播放策略在真机可能有差异。
2. **en-US 译文未经母语审校**：键一致性、占位符、英文界面无残留中文都有测试，措辞未润色。
3. **无埋点**：按隐私条款不加载第三方脚本，PRD 8.6 的事件字典未接线，第 4 章 KR 只能作方向性目标。
4. **难度曲线在 600 m 饱和**：极长局会趋于平坦，需按上线后的死亡分布校准。
5. **性能 SLO 的“中端安卓”未实测**：60 fps 来自本机 GPU 的 headless 移动模拟。

## 六、运行

```bash
git clone https://github.com/Wjd0011/skyline-runner.git
cd skyline-runner
npm run serve            # http://127.0.0.1:8123
npm test                 # 51 条单元/属性测试
npm run test:e2e         # 72 条浏览器端到端（需 Chrome 或 Edge）
npm run test:memory      # 5 分钟堆增长
```

无构建步骤：任何静态服务器直接托管仓库根目录即可。
